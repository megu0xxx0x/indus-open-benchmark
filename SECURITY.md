# Security and Data-Rights Reports

Do not include private collection records, embargoed excavation data, credentials, or unlicensed
images in a public issue.

For vulnerabilities in the public source repository, use the
[GitHub private vulnerability report](https://github.com/megu0xxx0x/indus-open-benchmark/security/advisories/new).
Do not put credentials, private collection records, or embargoed evidence in
a public issue.

For security or data-rights reports, provide:

- affected file, source ID, or artifact ID;
- whether the problem concerns security, privacy, provenance, or data rights;
- the source terms or evidence;
- the smallest safe reproduction;
- requested embargo or takedown timing.

Mark data-rights reports `DATA RIGHTS`. Suspected credentials must be rotated before history is
rewritten or a release is made.
